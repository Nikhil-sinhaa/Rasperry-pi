# Privacy threat model (PS2 evidence document)

## Assets

Private uploads; extracted text; chunk text; embedding vectors; user questions; model prompts/responses; source filenames/page metadata; cited quotes; transient chat history.

## Intended trust boundary

The browser, Streamlit app, Ollama HTTP API, model weights and embedding model are expected to run on the same computer. The application only accepts `http://127.0.0.1`, `http://localhost`, or `http://[::1]` for Ollama and rejects other hosts. The Streamlit server binds to `127.0.0.1`. Requests use a session with inherited proxy environment variables disabled. Embeddings and retrieval are computed in the process using local vectors; prompts are posted to the local Ollama API. Streamlit usage statistics are disabled.

## Data-flow controls in code

| Data | Processing | Persistence/network behavior |
|---|---|---|
| PDF/TXT bytes | `legal_triage/ingestion.py` | Read from in-memory upload; parser uses `BytesIO`; app does not write the document to disk |
| Extracted text and chunks | page-aware chunker | Kept in session index; not logged by project code |
| Embeddings | Ollama `/api/embed` over loopback | Generated by local model; vectors kept in process memory |
| User question and retrieved excerpts | `legal_triage/agent.py` | Sent only to configured loopback Ollama API; remote endpoint blocked by config validation |
| Model output | JSON parser and grounding checks | Raw completion is not shown or logged; only findings with valid source IDs and verbatim quotes are displayed |
| Temporary session state | Streamlit session | Clear button drops app's document index and chat state; this is not a secure RAM wipe |

## Threats addressed

- Accidental cloud API use: no cloud LLM/embedding package or external endpoint is configured in the runtime code; loopback URL is enforced.
- Proxy redirection: the app's requests client does not inherit `HTTP_PROXY`/`HTTPS_PROXY` environment settings.
- Cloud model tags: configured model names ending in common Ollama cloud suffixes are rejected; local tag presence is checked.
- Streamlit analytics: `gatherUsageStats = false` is configured.
- Prompt injection in documents: document excerpts are explicitly marked untrusted and must not be followed as instructions.
- Fabricated citations: unknown source IDs and non-verbatim/short quotes are dropped before UI display.
- Unsupported legal verdicts: common enforceability/validity/signing questions trigger a deterministic refusal/escalation response.
- Accidental disk writes by project code: the PDF parser uses in-memory streams; no persistent index/upload path is implemented.

## Threats not solved

This code does not prove semantic entailment between a claim and its quote; it cannot guarantee Gemma correctness; it does not encrypt process memory; it does not isolate concurrent OS users; it does not defend against compromised packages or OS/runtime; it does not include OCR; it does not inspect system-wide outbound traffic by itself; and it cannot make the host offline. Model/runtime telemetry or update behavior must be checked separately. Disable Ollama cloud features in the Ollama *server process* with `OLLAMA_NO_CLOUD=1`, and verify the setting.

## Reproducible evidence protocol

1. Record source commit/hash and model tags; do not include private documents.
2. Download weights/dependencies during setup, then disable the network or disconnect Wi-Fi.
3. With networking disabled, start Ollama and Streamlit locally, upload the included synthetic sample, ask a known-answer question, an absent-information question, a legal-verdict question, and a prompt-injection question.
4. Capture non-loopback traffic using `scripts/capture_network.sh` or the command in README. Record interfaces, duration and exact setup. Keep raw packet captures out of the public repo unless reviewed; a concise, redacted text summary is normally safer.
5. Run `python scripts/static_privacy_audit.py` and `python scripts/run_evals.py`; preserve actual outputs. Static checks and smoke tests are supporting evidence, not substitutes for the offline run.
